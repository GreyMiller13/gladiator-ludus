# Лудус: Кровь и Песок

Браузерная игра о ланисте, хозяине школы гладиаторов в Древнем Риме.

**Играть:** https://greymiller13.github.io/gladiator-ludus/

## Об игре

- Покупайте рабов на рынке, тренируйте их и с 5-го уровня посвящайте в одну из восьми школ: мурмиллон, ретиарий, секутор, фракиец, димахер, гопломах, сагиттарий, галл. У каждой школы видно, какие характеристики ей нужны.
- Сражайтесь на аренах Помпей, Капуи, Рима и в Колизее, автобоем или вручную на тактическом поле с препятствиями.
- Ход строится на очках действия. Их число растёт с ловкостью, шаг стоит 1, удар 4, неистраченные очки дают уклонение. Удар в спину вдвое чаще критический, а окружённый с двух сторон не может отступить.
- У каждого бойца есть мощь, оценка его силы в бою. Каждый день на младшей арене есть посильный бой.
- Проигравших судит толпа: *missio* или *iugula*. Кто успел повергнуть противника, чаще получает пощаду.
- Снаряжение видно на бойце: кузница, лавка редкостей, трофеи и реликвии великих гладиаторов.
- Заказы горожан (бои не насмерть), достижения и финал, Игры за рудис свободы.
- Можно выйти меньшинством, на бойца меньше противника, за двойную награду.
- Ставки на бой дня у менял у ворот амфитеатра.
- История: отец оставил вам лудус в Помпеях и долг в 5000 денариев. Платёж списывается сам раз в 7 дней, и если денег не хватит, лудус отберут. Четыре главы, хозяева арен, сцены с наставником, ростовщиком, соперником и сенатором.
- Обучение ведёт наставник Ферокс, оно занимает два игровых дня.
- Знамя лудуса: десять вариантов на выбор при новой игре, знамя выбирается на всю игру и стоит в шапке вкладки «Лудус».
- В шапке вкладки «Лудус» бойцы тренируются: пары бьются по очереди, боец без пары работает на манекене, лучники стреляют по мишеням, раненые отдыхают на песке.

Игра встречает главным меню: продолжить, новая игра, сохранение, справочник и настройки (звук, музыка, масштаб). Прогресс хранится в браузере. Чтобы перенести его на другое устройство, скачайте файл в разделе «Сохранение» и загрузите его там.

## Запуск локально

Игра работает без сборки. Откройте её через любой локальный сервер, например:

```
npx http-server -p 8765 .
```

и перейдите на http://localhost:8765.

## Тесты и инструменты

Логика игры проверяется без браузера (нужен Node 22+):

```
node tests/run.js
node tests/combat-hotkeys.test.cjs
```

- `node tests/sim.js [прогонов] [дней]` прогоняет историю с автобоем, чтобы подбирать расписание долга.
- `node tools/balance.js [уровень]` сравнивает школы в дуэлях и боях 3 на 3.

Для проверки публикации установите инструменты разработки и Chrome:

```
npm ci
npx playwright install chrome
npm test
npm run build
npm run test:release
npm run test:ui
```

`npm run build` упаковывает `index.html`, `css/`, `js/` и `assets/` в `_site/`, проверяет синтаксис JS и обновляет версии подключаемых файлов по их содержимому. Проверка публикации запускает именно `_site/` в Chrome по вложенному пути, как на GitHub Pages: загрузка всех изображений, новая кампания, вкладки, справочник, ставки и сохранение. Для проверки опубликованной версии задайте `SITE_URL`, при необходимости `EXPECTED_REVISION` с SHA коммита.

`npm run test:ui` выполняет полный набор проверок интерфейса и боёв на упакованном сайте. Отчёты сохраняются локально в `output/playwright/`, скриншоты не создаются.

В `.github/workflows/pages.yml` настроены проверка и публикация. При push в `main` GitHub Actions запускает тесты, упаковывает сайт вместе с изображениями, проверяет его в Chrome и только затем публикует на GitHub Pages. Pull request проходит проверки без публикации. Доступен и ручной запуск workflow.

В репозитории находятся рабочая игра, используемые изображения, тесты и инструменты проверки. Локальные макеты, арт-промпты, отчёты и одноразовые скрипты переноса исключены через `.gitignore`. Для запуска и публикации они не нужны. Изображения фонов и сюжетных персонажей загружаются из `assets/`; бойцы, предметы, знамёна, анимация, звук и музыка создаются кодом. Из внешних ресурсов используются шрифты Google Fonts. npm-зависимости нужны только для проверки, игра работает без них.

В ручном бою: **A** выбирает обычную атаку, **S** умение, **D** оборону, **Пробел** завершает ход, **P** переключает паузу. Эти же физические клавиши работают в русской раскладке.
