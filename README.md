# Лудус: Кровь и Песок

Браузерная игра про ланисту — хозяина школы гладиаторов в Древнем Риме.

**Играть:** https://greymiller13.github.io/gladiator-ludus/

## Об игре

- Покупайте рабов на рынке, тренируйте их и с 5-го уровня посвящайте в одну из восьми школ: мурмиллон, ретиарий, секутор, фракиец, димахер, гопломах, сагиттарий, галл.
- Сражайтесь на аренах Помпей, Капуи, Рима и в Колизее — автобоем или в пошаговом тактическом режиме на поле с препятствиями.
- Проигравших судит толпа: *missio* или *iugula*. Повергнувший противника имеет куда больше шансов на помилование.
- Снаряжение видно на бойце: кузница, лавка редкостей, трофеи и реликвии великих гладиаторов.
- Ежедневные заказы не насмерть, достижения и финал — «Игры за рудис свободы».

Игра встречает главным меню: продолжить, новая игра (с обучением по вкладкам, его можно отключить галочкой), сохранение и справочник. Прогресс сохраняется в браузере (localStorage). Чтобы перенести его на другое устройство, откройте «Сохранение»: там можно скачать файл сохранения и загрузить его в другом браузере. Меню открывается кнопкой «Меню» в шапке.

## Запуск локально

Игра — статическая страница без сборки. Откройте её через любой локальный сервер, например:

```
npx http-server -p 8765 .
```

и перейдите на http://localhost:8765.

Вся графика, анимация, звук и музыка генерируются кодом прямо в браузере — внешних ресурсов, кроме шрифтов Google Fonts, нет.
